# DapurKita

DapurKita is a platform that connects underused or not-yet-operational kitchens with hotels, factories, offices, schools, event organizers, and catering buyers.

## MVP goals
- Public directory of kitchen facilities
- Buyer request form for recurring catering and food-supply needs
- Kitchen owner onboarding form
- Matching and inquiry workflow (prototype; no live backend yet)
- Responsive Indonesian-first interface

## Local development

```bash
npm install
npm run dev
```

This initial prototype uses React, TypeScript, and Vite. Forms are demonstration-only until a backend and data storage are configured.

## Cloudflare Pages
- Build command: `npm run build`
- Build output: `dist`
